# ✈️ Flight Fare Prediction Using Python and Machine Learning

## 📌 Project Overview

Flight Fare Prediction is a Machine Learning project that predicts flight ticket prices based on different flight-related features.

The project includes:

- Data analysis
- Data preprocessing
- Data visualization
- Machine Learning model training
- Model evaluation
- Flight fare prediction
- Streamlit web application

## 🎯 Objective

The objective of this project is to predict the price of a flight using features such as:

- Airline
- Source city
- Destination city
- Class
- Day
- Month
- Departure hour
- Arrival hour
- Flight duration
- Number of stops

## 📊 Dataset

The project was developed using a cleaned flight fare dataset.

Dataset statistics:

| Feature | Value |
|---|---:|
| Rows | 300,257 |
| Columns | 25 |
| Airlines | 8 |
| Source cities | 6 |
| Destination cities | 6 |
| Missing values | 0 |
| Duplicate rows | 0 |

> **Note:** The full dataset is not included in this GitHub repository because of its file size.

## 🤖 Machine Learning Model

A **Random Forest Regression** model is used to predict flight fares.

The dataset was divided into:

- Training data: 240,205 rows
- Testing data: 60,052 rows

## 📈 Model Performance

| Metric | Result |
|---|---:|
| MAE | 1149.62 |
| RMSE | 2535.47 |
| R² Score | 0.9876 |

The R² score of **0.9876** indicates that the model explains approximately **98.76% of the variation in the test-set flight fares**.

## 📊 Data Visualization

The project includes visualizations such as:

1. Average fare by airline
2. Average fare by number of stops
3. Average fare by class
4. Top 10 routes by average fare

6. Average fare by flight duration

## 🌐 Streamlit Application

The trained Machine Learning model is connected to a **Streamlit web application**.

The application allows users to enter flight details and click **Predict Flight Fare** to obtain an estimated ticket price.

> **Note:** The trained model file is not included in this repository because of its large file size. The model can be generated by running the model training script.
